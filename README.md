# 🕉️ Satyanarayan Puja & Katha

A production-ready **React Native Android application** that provides users with Satyanarayan Puja Vidhi, Katha, Aarti, Stuti, Havan Vidhi, Puja Samagri and other essential information required to perform the puja.

The application is designed with a simple, accessible interface and provides **offline access to devotional content**, allowing users to use the app without requiring a continuous internet connection.

📱 **Available on Google Play:**  
https://play.google.com/store/apps/details?id=com.pujapadhati.satyanarayan

---

## 📱 About the Application

**Satyanarayan Puja & Katha** is a Hindi devotional application built with React Native and published as a production Android application on Google Play.

The app brings the important components of Satyanarayan Puja together in one place so users can easily access the required procedures, katha, aarti, stuti, havan vidhi and samagri information during their puja.

The application uses locally available content to provide a reliable **offline-first experience** and has been released and maintained through multiple production updates.

## ✨ Key Features

### 🪔 Puja Vidhi

Step-by-step information for performing Satyanarayan Puja.

### 📖 Satyanarayan Katha

Complete Hindi Satyanarayan Katha organized for easy reading.

### 🙏 Aarti & Stuti

Devotional Aarti and Stuti content available directly inside the application.

### 🔥 Havan Vidhi

Information and guidance for performing the Havan associated with the puja.

### 🛍️ Puja Samagri

A dedicated list of materials required for performing the puja.

### 🕐 Puja Timing Guidance

Useful information related to the appropriate timing for performing the puja.

### 📶 Offline Access

Core devotional content is bundled/stored locally so users can access the content without continuous internet connectivity.

### 💰 AdMob Monetization

Integrated **Google AdMob** to monetize the production application through advertisements.

### 🔄 Production Updates

The application has been published on Google Play and is maintained through production releases and updates.

## 🏗️ Application Architecture

The application follows a component-based React Native architecture.

```text
Satyanarayan Puja & Katha
│
├── App Navigation
│
├── Home Screen
│
├── Puja Vidhi
│
├── Katha
│
├── Aarti
│
├── Stuti
│
├── Havan Vidhi
│
├── Puja Samagri
│
└── Local Content / Offline Data
```

The application keeps the devotional content locally available, reducing dependency on network connectivity and allowing users to access important content during the puja.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

- Node.js
- npm
- Git
- Android Studio
- Android SDK
- Expo CLI / Expo tooling

### Clone the repository

```bash
git clone https://github.com/Pannakbhushana/Satyanarayan-puja-katha.git
```

### Navigate to the project

```bash
cd Satyanarayan-puja-katha
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npx expo start
```

### Run on Android

```bash
npx expo run:android
```

> Android Studio and a configured Android SDK are required for building and running the native Android project locally.
